# samkill-ui 실행 순서 / 2026-10-20

사용자 요구: uibowl-research → reference-decompose → reference-to-ui 순서로 실행한다.

기존 samkill-ui는 reference-to-ui를 먼저 읽도록 안내하고 조사는 부족할 때 추가하는 분기로 설명했다. 특정 과거 실행 로그는 없으므로 실제 실행의 단일 원인으로 단정하지 않는다. 조사·분해·구현의 순서와 인계 조건을 명시하고 직접 reference-to-ui를 호출해도 선행 자료가 없으면 조사·분해부터 수행하도록 수정했다.

## 작성자 수동 계약 대조

| 입력 | 수정한 지침에서 확인한 경로 |
|---|---|
| 새 UI / 자료 없음 | 조사로 이미지·출처 확보 → 분해 계약 → 설계·구현 → 리뷰 |
| 원본 이미지만 있음 | 조사 단계에서 적합성 확인·재사용 → 분해 → 구현 |
| 유효한 이미지와 분석 있음 | 조사·분해 단계에서 적합성 확인 후 재사용 → 구현. 재검색·재작성 불필요 |
| 검색만 요청 | 조사에서 종료. 구현으로 확대하지 않음 |
| 인증 실패 | 실패를 기록하고 제공 이미지·기존 계약으로 가능한 범위를 확인. 없으면 검증 완료로 바꾸지 않음 |
| reference-to-ui 직접 호출 / 자료 없음 | 진입 조건에 따라 조사 → 분해 후 설계·구현으로 복귀 |
| 기존 계약 내 국소 수정 / 문구만 | 해당 범위의 기준 적용. 새 조사 강제 없음 |

이는 지침의 수동 대조다. 실제 UIbowl 호출, 독립 에이전트의 실행 순서 재현, 제품 렌더 검증은 수행하지 않았다. 파일 검증 결과는 세션 맥락 기록에 남긴다.
