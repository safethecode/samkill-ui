# Spacing Audit 기준 — 수동 계약 대조

작성일: 2026-10-11. 대상은 스킬 문서의 행동 계약이다. 아래는 작성자가 합성 입력을 문서와 대조한 결과이며 독립 모델 실행·실제 UI 감사·렌더 검증 결과가 아니다.

## 요청과 선택

사용자가 제공한4/8pt 감사 방식을 기존 디자인 스킬에 적용한다. 별도 스킬 대신 [참고 문서](../../skills/reference-to-ui/references/spacing-audit.md)를 추가하고 구현·토큰·리뷰·samkill-ui 진입점과 AGENTS/DESIGN을 연결했다. 원문의 기본 목록에는20이 없지만 내부 간격에는 명시되어 있으므로 **내부20만 허용값으로 정리**했다. 비4배수 고정값과 구조의 비8배수 검토 의견을 구별하며 기존 변수/토큰은 보존한다.

## 검증 범위와 남은 일

- 변경 관련10개 문서의 로컬 링크 경로231개·신규 참고 문서 앵커3개·신규 파일 공백 및 git diff --check 통과. 변경3개 스킬의 quick_validate와 개인 설치 연결3개를 확인했다. 기존 링크 전체 앵커 검증은 수행하지 않았다.
- 기존 활성 실패 ORC-F12/G07/G20·RUI-22를 보존한다. 새 blocking 규칙·catalog 버전·게이트 판독기를 변경하지 않았으며 제품 게이트를 실행한 결과가 아니다.
- 기존 데모·제품 코드·토큰과 관련 없는 미커밋 파일은 변경하지 않는다. 작성 시점에는 커밋/푸시를 실행하지 않았으며, 후속 사용자 승인에 따른 분리 반영 범위는 세션 기록에 남긴다.
- 실제 Figma/웹 페이지의 감사 수치, 수정 전후 렌더/행동, 별도 모델의 스킬 수행 효과는 미검증이다. 스킬 적용 시 해당 대상에서 요약→간격 수정→실제 재검증을 수행해야 한다.
