# samkill-ui 실행 누락 보강 — 2026-10-10

사용자는 통합 호출이 모든 필요한 스킬을 제대로 실행하지 않는 것 같다고 지적했다. 구체 실행 로그는 제공되지 않았다. 기존 진입점은 읽기·적용을 지시하지만 실제 읽은 경로와 적용 증거를 연결하는 절차가 없으며, 기존 합성 평가는 전체 제품 실행의 누락 방지를 입증하지 않는다. 특정 실패 실행의 원인을 확정한 것으로 확대하지 않는다.

선택: 스킬을 전부 강제 로딩하지 않고 요청에 필요한 항목의 읽기·적용·검증을 구별한다. 단계 변화, 핵심 화면 확장 전, 최종 전달 전에 누락을 확인한다. 표 요약은 종속 본문을 대신하지 않으며 기존 자료 재사용과 기준 읽기 생략을 구별한다.

파일 검사에서 기존 pdp-design 상대 링크의 대상이 저장소에 없음을 확인했다. 개인 설치 경로에는 SKILL.md가 존재하므로 해당 분기는 설치 목록의 실제 경로로 탐색하도록 교정했다. 이 결함이 사용자 경험 전체의 원인이라고 확정하지 않는다.

## 작성자 수동 계약 대조

| 합성 요청 | 변경 후 확인한 경로와 범위 |
|---|---|
| 충분한 원본 분석·DESIGN.md가 있는 한국어 가입 UI 구현 | reference-to-ui/decompose/review를 단계별로 읽고 기존 분석 경로와 적용 증거를 연결한다. ux-copy/onboarding-flow를 적용한다. 재검색·DESIGN.md 재작성은 불필요하다. |
| 구현 도중 빈 DESIGN.md와 동의·오류 복구 화면이 추가됨 | design-md/onboarding-flow와 변경 문구의 ux-copy를 추가하고 기존 적용 상태를 갱신한다. 구현 후 리뷰만으로 끝내지 않는다. |
| 레퍼런스 검색만 또는 오류 문구만 | 각각 uibowl-research 또는 ux-copy를 적용한다. 전체 구현·제품 시각 게이트를 추가하지 않는다. |
| 읽기 전용 리뷰·종속 경로 접근 실패 | 읽은 경로·검증 범위는 채팅에만 기록한다. 설치 목록 대체 경로도 실패하면 접근 불가와 영향 범위를 남긴다. 파일 생성이나 누락 스킬의 적용 주장을 하지 않는다. |
| 목록에는 모든 스킬 이름이 있으나 구현 증거·실제 읽기 없음 | 예정·읽음 상태를 적용·검증으로 올릴 수 없다. 수행 가능한 필수 항목이 남으면 실행을 이어간다. |

이는 작성자가 문서를 대조한 결과이며 독립 실행·제품 UI 렌더·실제 통합 호출의 장기 누락 방지 검증은 미실행이다. 보강은 로컬 작업에 유지하며 이번 레퍼런스 보강 푸시에 포함하지 않는다.

## 같은 날 후속 점검

사용자가 같은 우려를 다시 전달했다. 기존 “선택 기준이며 전부 거치는 체크리스트가 아니다”라는 표현은 해당하는 모든 분기를 확인해야 한다는 의무를 약하게 만들 수 있다. 모든 분기의 적용 여부를 판단하고 해당 스킬은 전부 적용하도록 바꿨다. 설계·구현·핵심 화면 확장·최종 전달별 필요한 결과를 추가하고 종속 본문의 필수 참고 문서도 실제 읽은 경로와 적용 증거에 포함했다. UI 메타데이터 기본 프롬프트와 README·DESIGN 안내를 동기화했다.

이번 점검의 여러 파일 읽기 결과에서 도구 출력 잘림을 관찰했다. 이는 누락 위험의 한 사례이며 사용자 이전 실행의 원인으로 확정하지 않는다. 잘린 읽기 결과는 분할해 다시 읽어야 한다는 기준을 추가했다.

실제 설치 검사: samkill-ui 및 관련7개 스킬의 개인 경로가 관리 원본으로 연결되고 SKILL.md 바이트가 일치했다. 오래된 사본 때문에 발생했다고 판단할 근거는 없다. 설치 접근 성공과 실행 시 읽기·적용 성공은 별개다.

[공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills)는 초기 메타데이터와 선택 후 본문 로딩을 구별한다. 이를 근거로 통합 진입점의 상대 링크만으로 종속 본문까지 자동 적용된다고 가정하지 않도록 했다. 문서 변경은 실행 지침 보강이며 런타임의 강제 실행 장치를 추가한 것은 아니다.

| 추가 수동 입력 | 계약 대조 결과 |
|---|---|
| 종속 본문을 읽었지만 한국어 글쓰기·토큰·게이트 참고 기준은 빠짐 | 스킬 단위 기록만으로 완료할 수 없으며 현재 단계의 필수 참고 문서와 적용 근거를 추가한다. |
| 합쳐 읽은 도구 출력이 잘림 | 생략된 본문을 다시 읽기 전 전체 읽음으로 기록할 수 없다. |
| 대표 구현 스킬만 적용하고 가입·한국어 문구 분기 생략 | 모든 분기의 적용 여부 확인에서 해당 항목으로 분류하고 그 단계까지 읽기·계약 결과를 보완한다. |
| 기존 분석과 빌드 성공만으로 의존 화면을 확장 | 핵심 화면의 실제 렌더 비교·수정 증거가 필요하다. 기존 자료와 빌드는 이를 대체하지 않는다. |

추가 대조도 작성자의 수동 검토다. 전체 제품 작업의 독립 실행·브라우저 비교·장기 누락 방지 효과는 여전히 미검증이다. 로컬 파일 검증 결과는 아래 후속 기록에 남긴다.

후속 파일 검증: samkill-ui quick_validate, UI 메타데이터 YAML, 관련 문서의 로컬 링크 경로168개, git diff --check 통과. 개인 설치8개 스킬의 본문과 관리 원본이 일치했다. 링크 앵커·제품 실행·앱의 UI 메타데이터 갱신은 미검증이다.
